02

클라우드 보안 탐색

이 분야가 실제로 무슨 일을 하는지, 지금 나한테 있는 것과 없는 것, 자격·채용 조건을 실제 자료로 정리.

클라우드 보안은 뭘 하는 일일까

회사가 AWS라는 큰 건물에 사무실을 빌려 쓴다고 생각해 보자. 건물 자체(데이터센터, 하드웨어)는 AWS가 지키지만, 사무실 문단속·출입카드 발급·CCTV는 회사 몫이다. 이걸 공동 책임 모델이라고 부르고, 클라우드 보안 엔지니어는 이 “사무실 안쪽”을 맡는다.

실제 공고에 나온 주요 업무

  • 권한 관리(IAM) — 꼭 필요한 만큼만 열어주기
  • 안전한 설계와 설정 점검 — 잘못 열린 설정 찾기
  • 로그·위협 탐지 자동화 — CloudTrail, GuardDuty, Macie
  • 컨테이너 보안 솔루션 운영
  • 보안 운영 자동화 — Python, Terraform
  • 컴플라이언스 — ISMS-P 등 인증 기준

필요한 역량

  • 기초 체력 — 리눅스, 네트워크
  • 클라우드 서비스 이해 — IAM, VPC, 로그·탐지 서비스
  • 자동화 — Python + Terraform (여러 공고에 공통)
  • 공격자 시선 — 어떻게 뚫리는지 알아야 막는다
  • 소통 — 개발자와 말이 통하는 능력

현재 가진 것 / 앞으로 준비할 것

현재 가진 것

  • CSPM 개념 이해 + 직접 만들어 본 경험
  • OpenStack으로 클라우드를 직접 올려본 경험
  • CTF 웹 해킹·리버싱 기초
  • Python, Docker, 멱등성 있는 자동화 스크립트
  • 리눅스·네트워크 자격증 준비로 쌓은 기초
  • 블로그·GitHub 기록 습관, 행사 운영 경험

앞으로 준비할 것

  • AWS 실전 — IAM 정책, VPC, CloudTrail·GuardDuty 직접 켜보기
  • Terraform — 공고마다 나오는 단골 기술
  • 컨테이너·쿠버네티스 보안
  • 컴플라이언스 감각 — ISMS-P가 요구하는 것
  • 영어 문서 읽기
  • 프로젝트 정리 — 하는 일을 클라우드 보안 한 축으로

겨울방학 계획을 작게 줄여서 앞당겼다. AWS 계정 없이 문서만 보고 할 수 있어서 요금 걱정이 없다.

시작할 활동

OpenStack CSPM 점검 룰을 AWS로 대응시켜 보기

기간과 시간

10/24(토) ~ 11/22(일)
주말 하루 1시간 (가정, 실제 시간 미확인)

30일 결과물

CSPM 룰 3개 ↔ AWS 매핑표 + 블로그 초안 1편

주별 계획

11/8 OSINT 대항전과 11/10 경진대회 접수 마감이 몰린 2~3주차는 15분짜리 최소 행동만 넣었다.

주차무엇언제남길 결과확인 방법
1주차
10/24~11/1		CSPM 룰 3개 고르기 → 각각 AWS의 어떤 서비스·설정에 해당하는지 문서 찾기주말 하루 1시간룰 3개와 대응 AWS 서비스 이름Notion에 3줄이 채워졌는지
2주차
11/2~11/8		최소 행동: 매핑표 틀만 만들기 (OpenStack 룰 / AWS 대응 / 차이점)11/7(토) 전 15분빈 표표가 존재하는지
3주차
11/9~11/15		최소 행동: 룰 1개만 표에 채우기11/10 제출 뒤 15분1행 완성1행이 채워졌는지
4주차
11/16~11/22		나머지 2개 채우기 → 블로그 초안 쓰기11/21(토) 1~2시간매핑표 3행 + 블로그 초안블로그 저장소에 초안이 올라갔는지

도움을 요청할 사람

  • APS CSPM 동아리원 — 고른 룰이 프로젝트를 대표하는지, 용어가 맞는지
  • AWS를 써본 사람 (동아리·KUCIS에 있다면) — 매핑이 맞는지 검토
  • 초안 읽어줄 친구 한 명 — 보안 몰라도 이해되는지

예상 장애물과 대응

  • 11월 초 일정 겹침 → 15분 행동만, 못 하면 4주차에 몰아서
  • 룰이 1:1로 안 맞음 → “대응 없음/부분 대응”도 기록. 그게 글의 핵심
  • 범위가 커짐 → 30일 동안은 3개로 고정
  • 영어 문서 → 한국어판 먼저, 영어판과 대조
  • 계정 만들고 싶어짐 → 기말 후 결제 알림과 함께

그래도 무리하면: 최소 버전

룰 1개만 매핑하고, 블로그 대신 Notion 메모로 남긴다. 4주차 1시간이면 끝나는 분량.

이번 주 첫 행동

이번 일요일(10/25)까지, CSPM 점검 룰 중에 AWS로 옮겨볼 3개를 골라 Notion에 한 줄씩 적는다.
