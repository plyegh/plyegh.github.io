Cloud Security

클라우드 보안은 뭘 하는 일일까

실제 공고와 공식 문서로 확인한 업무, 역량, 자격·채용 조건.

회사가 AWS라는 큰 건물에 사무실을 빌려 쓴다고 생각해 보자. 건물 자체(데이터센터, 하드웨어)는 AWS가 지키지만, 사무실 문단속·출입카드 발급·CCTV는 회사 몫이다. 이걸 공동 책임 모델이라고 부르고, 클라우드 보안 엔지니어는 이 “사무실 안쪽”을 맡는다.

업무

실제 공고에 나온 주요 업무

  • 권한 관리(IAM) — 꼭 필요한 만큼만 열어주기
  • 안전한 설계와 설정 점검 — 잘못 열린 설정 찾기
  • 로그·위협 탐지 자동화 — CloudTrail, GuardDuty, Macie
  • 컨테이너 보안 솔루션 운영
  • 보안 운영 자동화 — Python, Terraform
  • 컴플라이언스 — ISMS-P 등 인증 기준
역량

필요한 역량

  • 기초 체력 — 리눅스, 네트워크
  • 클라우드 서비스 이해 — IAM, VPC, 로그·탐지 서비스
  • 자동화 — Python + Terraform (여러 공고에 공통)
  • 공격자 시선 — 어떻게 뚫리는지 알아야 막는다
  • 소통 — 개발자와 말이 통하는 능력
