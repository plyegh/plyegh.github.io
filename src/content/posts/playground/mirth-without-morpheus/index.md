## 한 줄 요약

72시간 밤을 새도 웃으면 건강하지 않을까에 대한 연구

## 1. 왜 이런 걸 썼나

"웃음은 최고의 명약"이라는 말과 "잠은 죽어서 자면 된다"는 말이 있다. 그럼 둘을 동시에, 72시간 동안 실행하면 건강해질까? 시험 기간에 한 번쯤 해 봤을 고민을 진지한 척 문헌으로 따져 봤다.

## 2. 안 자면 생기는 일

| 깨어 있는 시간 | 문헌이 말하는 것 |
| --- | --- |
| 17시간 | 수행 저하가 혈중알코올농도 0.05% 수준 (음주 단속 기준 초과) |
| 24시간 | 0.10% 수준 (면허 취소 기준 초과), 뇌 포도당 대사 약 8% 감소 |
| 약 35시간 | 편도체 반응 약 60% 증가, 새 기억 부호화 약 40% 저하 |
| 48~50시간 | 농담을 못 알아듣기 시작. 커피로도 안 돌아옴 |
| 48~90시간 | 복합 환각, 사고 장애 |
| 72시간 | 망상 출현 |

더 무서운 건 **본인은 멀쩡하다고 느낀다**는 점이다. 24시간 밤샘한 대학생들은 시험을 더 못 보고도 자기가 더 잘했다고 평가했다.

## 3. 웃으면 좋아지는 것

웃음의 효과 중 가장 엄밀하게 측정된 건 열량 소모다. **분당 0.19 kcal.**

72시간을 쉬지 않고 웃는다는 불가능한 가정을 해도 약 **821 kcal**. 같은 기간 수면 부족으로 허기는 24% 늘어난다. 야식 한 끼면 끝이다.

통증 역치가 오르고 코르티솔이 내려간다는 연구도 있지만, 그 실험의 참가자들은 전부 **전날 밤에 잠을 잔 사람들**이다.

## 4. 그럼 밤샘 중에 왜 자꾸 웃음이 나올까

논문의 핵심 주장, 이름하여 **웃음의 역인과 가설**이다.

1. 수면박탈은 농담을 **해독하는** 전전두엽을 약하게 만든다.
2. 동시에 농담에 **반응하는** 보상 회로는 과민하게 만든다.
3. 즉 사흘째의 웃음은 더 웃겨서가 아니라 **덜 막혀서** 나온다.

> 웃음은 약이 아니라 체온계에 가깝다. 눈금이 올라간다고 환자가 건강해지지는 않는다.

## 5. 잠 깨는 방법 비교

실제 연구들의 처치군을 하나의 실험처럼 재배열한 12개 가상 실험군 중 주요 방법만 추렸다.

| 방법 | 결과 |
| --- | --- |
| 그냥 버티기 | 위에 적은 일이 전부 일어남 |
| 카페인 600 mg | 덜 졸리고 반응은 빨라짐. 농담 이해는 그대로 |
| 각성제 | 가장 센 약으로도 언어 유머 이해는 회복 안 됨 |
| 매운 음식 | 밤샘 조건의 근거 없음. 자려는 사람의 잠은 방해함 |
| 찬 바람, 라디오 | 효과 미미하거나 잠깐 |
| 밝은 빛 | 각성도는 오르지만 이후 수면이 밀림 |
| 웃음 | 농담을 이해해야 웃는데, 그 능력이 먼저 사라짐 |
| **20분 낮잠** | **수행과 각성도 향상. 근거가 가장 일관됨** |

정리하면, 유일하게 통한 방법은 **잠**이었다. 불닭볶음면은 수면 압력을 낮추지 못한다.

## 6. 결론

1. 72시간 각성의 비용은 크고, 일부는 첫 24시간 안에 시작된다.
2. 웃음의 이득은 작고, 잠을 잔 사람에게서만 확인됐다.
3. 커피, 매운 음식, 찬 바람 중 수면을 대신한 것은 없었다.
4. 사흘째의 웃음은 처방이 아니라 소견이다.

> [!TIP]
> 가장 비용 효과적인 방법은 **먼저 자고, 일어나서 웃는 것**이다.
